### How to start
This repo has 2 services in docker
1. main app which is http service for create/update product to database
2. postgres database

To run all, using
```
./run_service.sh
```

by default will serve at localhost:8080.

For documents path `http://localhost:8080/api-docs/`

To stop service use
```
./stop_service.sh
```

To run test use
```
./run_test.sh
```
